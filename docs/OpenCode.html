O repositório é um aplicativo web React chamado mm3e-builder, que serve como um construtor de personagens para o jogo de RPG de mesa Mutants & Masterminds 3ª Edição (M&M 3e).

Aqui está um resumo do que ele faz:

1. Construção de Personagens

Permite criar e gerenciar fichas de personagem completas, incluindo:

  • Abilidades: Força, Vigor, Agilidade, Destreza, Luta, Inteligência, Atenção e Presença.
  • Defesas: Esquiva, Parada, Fortitude e Vontade.
  • Habilidades (Skills): Mais de 28 perícias com subtipos (ex: "Especialização: História").
  • Vantagens (Advantages): 49 vantagens com sistema de busca/filtro.
  • Complicações: Ganho de Hero Points.

2. Construtor de Poderes (Power Builder)

Um recurso avançado e visual para criar poderes complexos:

  • Efeitos: Lista de 200+ efeitos (ataques, movimento, controle, etc.).
  • Modificadores (Extras/Defeitos): Arrastar e soltar para adicionar modificadores aos efeitos.
  • Arrays (Efeitos Alternativos): Suporte completo a poderes com efeitos alternativos.
  • Cálculo em Tempo Real: Preço atualizado automaticamente conforme os modificadores são adicionados.

3. Funcionalidades Técnicas

  • Exportação:
    • PDF: Preenche automaticamente uma ficha oficial editável.
    • Excel: Gera uma planilha estilizada com todas as seções.
  • Persistência: Auto-salvamento automático no navegador (localStorage).
  • Internacionalização: Suporte a Inglês e Português (Brasil).
  • Tema: 4 temas visuais (Dark Knight, Arc Reactor, Cyberpunk, Light Print).

4. Tecnologias

Feito com React moderno (v19), TypeScript, Vite, Zustand (gerenciamento de estado), e bibliotecas específicas para PDF e Excel.

Resumo: É uma ferramenta web completa para jogadores de Mutants & Masterminds 3e, automatizando cálculos complexos e facilitando a criação de personagens e poderes com uma interface visual intuitiva.
